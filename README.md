## Projects

**[카페 주문 서비스 — Application](https://github.com/CLD-8th/project2-team02-cafe-app)**

Spring Boot · Java 21로 회원·메뉴·주문 API를 구현했습니다. Spring Security와 JWT로 권한을 분리하고, 쿠버네티스 헬스체크와 Prometheus 지표 노출까지 운영을 염두에 두고 설계했습니다.

**[카페 주문 서비스 — Infrastructure](https://github.com/CLD-8th/project2-team02-cafe-infra)**

Terraform으로 AWS 인프라를 코드로 구성했습니다. VPC와 public/private/isolated 서브넷, NAT, 보안 그룹 등 네트워크 레이어와 S3·ECR을 담당했고, 반복되는 리소스는 재사용 가능한 모듈로 분리했습니다.

**[DMember — Backend](https://github.com/Dmember/Dmember-back)**

인스타그램 DM을 AI가 정리해 주는 서비스의 백엔드입니다. JWT 인증과 인스타 계정 연동 기능을 구현했고, 헤더로 사용자 ID를 받던 기존 구조를 토큰 기반으로 바꿔 신뢰 경계를 정리했습니다.
